# 阴阳师御魂规则与常用黑话

## 御魂基础规则

每个式神可装备 6 个位置的御魂。1、3、5 号位主属性固定；2、4、6 号位可从若干主属性中选择。

| 号位 | 主属性 |
| --- | --- |
| 1 号位 | 固定攻击 |
| 2 号位 | 攻击加成、生命加成、防御加成、速度 |
| 3 号位 | 固定防御 |
| 4 号位 | 攻击加成、生命加成、防御加成、效果命中、效果抵抗 |
| 5 号位 | 固定生命 |
| 6 号位 | 攻击加成、生命加成、防御加成、暴击、暴击伤害 |

常用主属性简称如下：

| 简称 | 2 号位 | 4 号位 | 6 号位 | 常见用途 |
| --- | --- | --- | --- |
| 攻攻爆 | 攻击加成 | 攻击加成 | 暴击或暴击伤害 | 常规输出 |
| 生生爆 | 生命加成 | 生命加成 | 暴击或暴击伤害 | 生命型输出、治疗 |
| 速命生 | 速度 | 效果命中 | 生命加成 | 控制、功能辅助 |
| 速生生 | 速度 | 生命加成 | 生命加成 | 治疗、生存辅助 |
| 速攻攻 | 速度 | 攻击加成 | 攻击加成 | 速度输出、功能输出 |
| 速抵生 | 速度 | 效果抵抗 | 生命加成 | 抵抗、生存辅助 |

## 副属性与强化

一个御魂有 1 条主属性和 2 至 4 条初始副属性；副属性最终最多为 4 条。副属性包括：

- 速度、暴击、暴击伤害。
- 效果命中、效果抵抗。
- 攻击加成、生命加成、防御加成。
- 固定攻击、固定生命、固定防御。

御魂在 `+3 / +6 / +9 / +12 / +15` 各有一次强化判定，共 5 次。

- 初始为 2 条或 3 条副属性时，前期强化可能新增副属性，直到补满 4 条。
- 副属性已经为 4 条时，每次强化会随机提升其中一条。
- 每次成长存在不同数值档位，计算时应保留原始精度，不能只依据页面显示的两位小数反推完整过程。

### 强化次数、跳数与命中次数

“跳”“命中”“强化次数”都是指五次强化判定落到某条副属性上的次数，**初始就存在的副属性不算强化命中**。

例如初始带速度，后续五次强化全部命中速度：

- 展示强化命中次数时：速度命中 `5 次`。
- 从完整成长构成看：初始速度加 5 次强化，共有 `6 段`速度成长。

“最大一次成长值为 4”通常指成长档位质量，不应简单理解为任何属性都固定增加 4 点；各副属性对应的真实数值与精度不同。

## 套装规则

普通御魂包含两件套属性和四件套效果。

- `4 + 2`：一套四件套效果，加一套两件套属性。
- `2 + 2 + 2`：三种不同的两件套属性。
- 同一套装穿 4 件时，只获得一次该套的两件套属性，不会重复获得两次。

逢魔御魂应单独处理：

- 逢魔御魂的额外属性属于一件套效果。
- 装备多个逢魔御魂时，对应的一件套效果可分别生效。
- 荒骷髅、土蜘蛛、歌姬等不应机械套用普通御魂的两件套计算逻辑。

## 最终面板计算

一般形式为：

```text
最终属性 = 式神基础属性 + 主属性贡献 + 副属性贡献 + 套装属性 + 额外属性
```

攻击、生命、防御百分比按式神基础属性计算：

```text
最终攻击 = 基础攻击 × (1 + 攻击加成%) + 固定攻击
最终生命 = 基础生命 × (1 + 生命加成%) + 固定生命
最终防御 = 基础防御 × (1 + 防御加成%) + 固定防御
```

注意：攻击加成、生命加成和防御加成只乘对应的基础属性；固定属性不参与百分比放大。副本增益、技能增益等应作为“额外属性”单独加入。

速度计算为：

```text
最终速度 = 式神基础速度 + 御魂主属性速度 + 御魂副属性速度 + 套装或额外速度
```

暴击和暴击伤害应完整展示：

```text
最终暴击 = 基础暴击 + 御魂暴击 + 套装暴击 + 额外暴击
最终暴击伤害 = 基础暴击伤害 + 御魂暴击伤害 + 套装暴击伤害 + 额外暴击伤害
```

暴击超过 100% 仍属于真实面板，应完整显示；“满爆”约束仅表示最终暴击满足 `>= 100%`。

## 常用配装指标

以下指标用于比较候选御魂组合，具体式神技能倍率、御魂四件套伤害效果和副本机制需要在此基础上额外计算。

| 指标 | 常用计算方式 |
| --- | --- |
| 伤害指标 | 最终攻击 × 最终暴击伤害 |
| 治疗量指标 | 最终生命 × 最终暴击伤害 |
| 防御输出指标 | 最终防御 × 最终暴击伤害 |
| 速度指标 | 最终速度 |
| 命中指标 | 最终效果命中 |
| 抵抗指标 | 最终效果抵抗 |
| 命抗双修 | 最终效果命中 + 最终效果抵抗 |

“满爆伤害配装”的正确处理方式是：先将 `最终暴击 >= 100%` 作为硬约束，再在满足约束的组合中比较伤害指标；不能因为暴击超过 100% 而把面板截断或直接排除。

## 藏宝阁看号黑话

### 一速、散件一速、招财一速

“一速”可能指单件御魂的高速度副属性，也可能指账号能拼出的最高速度组合，使用时应结合上下文。

- **散件一速**：不限制四件套，从全仓各位置挑选最高速度御魂所能组成的理论最高速度。
- **招财一速**：满足招财猫四件套要求时，账号可以拼出的最高速度组合。

招财一速的实战意义通常高于单纯的散件一速，因为招财猫是斗技中常见的高速功能套装。

### 满速

“满速”通常指速度副属性达到最理想的强化结构：

1. 初始副属性已有速度。
2. 后续五次强化全部命中速度。
3. 完整速度由初始词条和五次强化组成，共 6 段成长。

统计“满速数量”时，应与“速度强化命中次数”分开理解：前者关注完整 6 段速度结构，后者展示时不把初始速度词条计入命中次数。

### 头、尾、头尾

这是高速招财体系的常用术语。

- **头**：2 号位主属性为速度，副属性带速度，且速度副属性后续强化命中 5 次。
- **尾**：4 号位主属性为效果命中，副属性带速度，且速度副属性后续强化命中 5 次。
- **头尾**：符合上述标准的速度头与命中尾的数量或质量。

头和尾是斗技控制、拉条、供火等式神的核心御魂，因此是账号御魂价值的重要指标。

### 满爆、超星、双爆

- **满爆**：最终暴击率 `>= 100%`，不要求刚好等于 100%。
- **超星**：最终速度 `> 128`。本意是指速度大于晴明。
- **双爆**：副属性同时拥有暴击和暴击伤害。
- **暴击套**：6 号位使用暴击主属性的输出组合。
- **爆伤套**：6 号位使用暴击伤害主属性的输出组合，通常需要其他部位补足暴击。

计算器必须同时考虑暴击六号位和暴击伤害六号位，不能预先假设某一类一定更优或一定不能满爆。

### 胚子、四条胚子、跳歪

- **胚子**：尚未强化完成，但初始词条结构有培养价值的御魂。
- **四条胚子**：初始就有 4 条副属性；五次强化都可直接提升已有词条。
- **三条胚子、两条胚子**：初始副属性较少，前期可能先补新词条，关键属性可获得的强化机会较少。
- **跳**：一次强化落到某副属性上，例如“速度跳三次”。
- **歪、跳歪**：强化落到当前用途价值较低的词条上，例如输出御魂连续强化防御或效果抵抗。

### 有效词条

“有效词条”不是所有式神共用的固定标准，而是相对具体目标而言。

| 目标类型 | 常见有效词条 |
| --- | --- |
| 输出 | 暴击、暴击伤害、攻击加成、固定攻击、速度 |
| 控制 | 速度、效果命中、生命加成、效果抵抗 |
| 治疗/生存 | 生命加成、速度、暴击伤害、效果抵抗、防御加成 |
| 命抗双修 | 效果命中、效果抵抗、速度、生命加成 |

### 命中、抵抗、命抗双修

- **命中**：效果命中。
- **抵抗**：效果抵抗。
- **命抗双修**：效果命中与效果抵抗的总值，即 `命中 + 抵抗`。


## 看号重点

看账号御魂价值时，常见优先级如下：

1. 招财一速与散件一速。
2. 招财头、招财尾和高速头尾数量。
3. 满速御魂数量与高速度副属性御魂。
4. 破势、网切、狂骨、隐念、海月火玉等核心输出套装完整度。
5. 荒骷髅、土蜘蛛、歌姬等逢魔御魂组合能力。
6. 满爆前提下的攻击、暴击伤害和目标式神最终面板。
7. 高命中、高抵抗、命抗双修御魂的数量与质量。

简要概括：

```text
速度看一速、招财一速、头尾和满速；
PVP 看招财、速度、命中、抵抗和功能套完整度；
PVE 看满爆前提下的攻击、暴击伤害、套装及逢魔组合。
```
