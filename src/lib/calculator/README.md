# 御魂计算器内核

这里存放与 React 页面无关、可由 Worker 独立执行的御魂计算领域代码。

## 约束

- `types.ts` 是计算请求、面板、过滤条件、进度和结果的唯一类型来源。
- `relicCalculator.ts` 暂时是兼容入口与受保护搜索内核。页面不得依赖其内部状态或私有辅助函数。
- Worker 只接收 `RelicCalculationRequest`，并继续维持现有的 `progress`、`done`、`error` 消息协议。
- 面板公式、四件套布局、两件套覆盖、暴击溢出排序和候选剪枝属于结果正确性的一部分。重构必须先补回归样本，再移动实现。

## 推荐拆分顺序

1. 属性归一化与御魂静态属性缓存。
2. 最终面板计算和指标求值。
3. 面板约束与候选上界剪枝。
4. 固定四件套布局搜索。
5. 全覆盖两件套搜索与 Worker 任务分片。

每次只迁移一个职责，并使用同一份请求比较旧、新结果的六件御魂 ID、最终面板和指标排序。
